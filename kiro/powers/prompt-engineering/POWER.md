# Prompt Engineering Tools

## Overview

Wraps the toolbox `prompt-mcp` binary so prompt tooling loads only when
working on prompts.

## Available MCP Servers

**prompt-mcp** (toolbox binary)

## Prerequisites

- `prompt-mcp` installed via toolbox and on PATH
