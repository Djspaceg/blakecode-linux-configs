# Concur Expenses

## Overview

Expense reporting through Amazon's Concur integration via the toolbox
`concur-mcp` binary.

## Available MCP Servers

**concur-mcp** (toolbox binary)

## Prerequisites

- `concur-mcp` installed via toolbox and on PATH
- Valid Midway session (`mwinit`) for auth
