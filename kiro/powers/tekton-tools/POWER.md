# Tekton Tools

## Overview

Wraps the toolbox `tekton-mcp` binary so it loads only for Tekton work.

## Available MCP Servers

**tekton-mcp** (toolbox binary)

## Prerequisites

- `tekton-mcp` installed via toolbox and on PATH
