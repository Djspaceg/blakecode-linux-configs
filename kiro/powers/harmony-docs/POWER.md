# Harmony Documentation

## Overview

Documentation search and code examples for Amazon's Harmony platform via the
toolbox `harmony-mcp` binary.

## Available MCP Servers

**harmony-mcp** (toolbox binary)

Tools (auto-approved):
- `harmony-search-documentation` - search Harmony docs
- `harmony-list-code-example-topics` - browse example topics
- `harmony-get-code-example` - fetch a specific code example

## Prerequisites

- `harmony-mcp` installed via toolbox and on PATH.
